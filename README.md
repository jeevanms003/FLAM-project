# Wandr - AI Trip Planner

A smart trip planner that generates structured daily itineraries using Groq and Llama. Built for the Flam Frontend Internship assignment.

🔗 **Live Demo:** [https://flam-project-5pik97n6x-jeevanms003.vercel.app/](https://flam-project-5pik97n6x-jeevanms003.vercel.app/)

## Tech Stack
- React (Vite)
- Tailwind CSS
- Groq API (`openai/gpt-oss-120b`)
- Express (Local Dev) / Vercel Serverless (Production)
- @dnd-kit (Drag and drop)

## Setup
1. `npm install`
2. Create `.env` with `GROQ_API_KEY=your_key`
3. `npm start`
